# Initial elliptic-logarithm coefficient bound

Research checkpoint, 2026-10-24, Asia/Shanghai. This is a human mathematical
argument with exact standard-library arithmetic certificates, **not a Lean
proof**. It gives an initial bound for the four length-six curves. It does not
supply lattice reduction, complete point enumeration, or a solution of k=6.
Actual arithmetic replays and the limits of the review process are recorded in
[VERIFICATION.md](../../docs/VERIFICATION.md).

## Statement and scope

Use the four models and displayed triples of points in the published
`../CAS.md`, with their given maps from
`a*Phi(V)=b*Phi(U)`. An admissible point has integer U,V at least 49, with the
original positive-square and interval restrictions. Suppose its image P is in
the subgroup generated by the three displayed points, and write

```
P = m1*P1 + m2*P2 + m3*P3,   M = max(|m1|,|m2|,|m3|).
```

Then the argument below proves **M < 10^100**. Coverage of the whole rational
point group additionally uses the previously recorded Magma full-basis flags.
Those flags are external CAS evidence, not consequences of this argument or
of the Lean polynomial certificates.

## Primary theorem and normalization

David, *Minorations de formes linéaires de logarithmes elliptiques*, Mémoires
SMF 62 (1995), §2, printed pp. 9–10, Théorème 2.1:
[official PDF](https://smf.emath.fr/system/files/filepdf/MSMF_1995_2_62__1_0.pdf).
Local `David1995.pdf (download separately; not vendored)`, SHA256
`aefffcbf1d8475a4f17ce95a0de0240db687a9108d0ced5d8d972c844dc504ae`.
The pages were visually rechecked for this application.

For each original model put z=x+a2/3 and w=2y. Then

```
w^2 = 4*z^3 - g2*z - g3,   dz/w = dx/(2*y).
```

David's k is **5**, comprising four nonperiod logarithms and the real period
as a logarithm of the identity. His theorem explicitly permits poles of the
Weierstrass function, so this fifth factor is allowed. Take five copies of the
same curve over `K=Q(alpha)`, where `alpha^3=b/a` and `[K:Q]=3`.
Tzanakis's corresponding count of nonperiod logarithms is 4; it must not be
substituted for David's k.

The proof in `HEIGHTS.md` reconciles David's canonical
height of the projective cubic with the x-normalized height used here:

```
hat_h_D = (3/2)*H.
```

It proves, for all four branches, `h=max(1,h([1:g2:g3]),h(j))<22`,
`hat_h_D(Q0)<20`, `hat_h_D(Pi)<8`, and `hat_h_D(O)=0`.
These are absolute heights; extension to K does not multiply them by three.
The note also proves that Q0 has degree exactly three, hence is not rational.

## Fundamental periods and the real lifts

Let r be the unique real root of `f(x)=x^3+a2*x^2+a4*x+a6`, and set

```
R = sqrt(f'(r)),   c = 3*r+a2,   m = (2-c/R)/4.
K(t) = integral_0^(pi/2) (1-t*sin(theta)^2)^(-1/2) dtheta.
```

The exact certificate `period_parameters.json`
proves all four cubic discriminants negative and `0<m<999/1000`.
The standard real-root period formulas give the positively oriented basis

```
Omega = 2*K(m)/sqrt(R),
omega2 = Omega/2 + i*K(1-m)/sqrt(R),
area = Im(conj(Omega)*omega2) = 2*K(m)*K(1-m)/R.
```

For a primary source with the factors checked, see Tzanakis, Acta Arith. 75
(1996), §7, printed p. 188:
[official PDF](https://matwbn.icm.edu.pl/ksiazki/aa/aa75/aa7525.pdf).
Local `Tzanakis1996.pdf (download separately; not vendored)`, SHA256
`00beb2e622143f0847590c85ca4adf07fecfb380468d68dc77e6f70ff7a203ff`.
His §3, printed p. 168, explicitly normalizes `omega*phi(P)` by the integral
of `dx/sqrt(q(x))`, confirming the `dx/y` convention. His stated §7 basis is
`Omega1+Omega2, Omega1-Omega2` on the short cubic. Its AGM expressions give `Omega1=2*K(m)/sqrt(R)` and
`Omega2=2*i*K(1-m)/sqrt(R)`. Divide that basis by two for our `dx/(2y)`,
then apply an integral unimodular basis change to obtain the basis above.
The transformed short cubic uses `e1=r+a2/3`, so `3*e1=c` and
`3*e1^2+A=f'(r)`. This tracks both the shift and the factor of two.

Elementary integral comparison now gives

```
Omega^2/area = 2*K(m)/K(1-m)
             <= 2/sqrt(1-m) < 2*sqrt(1000) < 64.
```

A reduced lattice basis exists. Replacing the basis by one in the usual
modular fundamental domain leaves `|omega1|^2*Im(tau)=area` unchanged, so no
assumption that the real period is a reduced basis vector is made.

Since each real curve is connected, choose centered real logarithms
`u(Pi),u(Q0),u(P)` in `[-Omega/2,Omega/2]`. The target map and Q0 lie on the
negative-y arc. There the lift is

```
u(x,y)=integral_x^infinity dt/(2*sqrt(f(t)))  (y<0).
```

The earlier continuous-path integral is therefore the difference of these
lifts, with no unrecorded period. The group law supplies an integer m0 with

```
u(P)=sum_i mi*u(Pi)+m0*Omega,
|m0| <= (3*M+1)/2.
```

Let `L=u(P)-u(Q0)`. It is nonzero: zero would identify the rational point P
with the nonrational point Q0. Define
`N=max(1,|m0|,|m1|,|m2|,|m3|)`. For M>=1, `N<=3*M+1<=4*M`.
The case M=0 already satisfies the asserted bound.

## Complete admissible David parameters

Use the five logarithms `(Omega,u(P1),u(P2),u(P3),u(Q0))`, coefficients
`(m0,m1,m2,m3,-1)`, and additive coefficient beta0=0. This linear form itself
is nonzero because its last coefficient is -1. Its value is L.
All coefficient heights are at most `log N`.

Choose

```
A = 1000,   log(Vi)=A for each i=1,...,5,
E = exp(1),   T=log(B)=max(log N,1000/3,66).
```

All point-height and curve-height requirements hold by the bounds above.
Every logarithm has absolute value at most Omega, so

```
3*pi*|ui|^2/(3*area) < 64*pi < 256 < A.
```

Consequently David's condition (4) permits E=e. Condition (1) is
`3*T>=A`, with the Vi already in nonincreasing order. Condition (2) follows
from `T>=log N` and `e*h<3*22=66`. This padded B treats small N directly;
no small-coefficient alternative is discarded.

For nonzero L, the contrapositive of David's theorem gives

```
log|L| > -C_D*3^12*(T+log(3)+1)*(log T+h+log(3)+1)^6*A^5,
C_D = 2.9*10^36*4^50*6^(1073/10).
```

The exact verifier checks

```
C_D*3^12*A^5
  < 29*10^35*4^50*6^108*3^12*1000^5 < 10^172.
```

Since `log(3)+1<3` and `h<22`, this implies the convenient weaker bound

```
log|L| > -10^172*(T+3)*(log T+25)^6.                 (1)
```

## Comparing with the existing upper bound

The earlier differential, integer-coordinate-height, and subgroup-height
arguments give

```
0<|L| <= 26892*exp(5-M^2/100).
```

These use the same `dx/(2y)` normalization. In particular
`log|L| < 20-M^2/100`, since `26892<2^15<e^15`.
Put `t=log M` and

```
F(t)=(t+1003)*(log(t+1000)+25)^6.
```

Because `log N<=t+log4<t+2`, one has `T<=t+1000` for t>=0.
Combining the upper bound with (1) yields the necessary inequality

```
M^2/100-20 < 10^172*F(t).                           (2)
```

Set `M*=10^100` and `t*=log M*`. Since `e^3>20>10`, `t*<300`.
The exact positive-series certificate for e^3 also gives `e^9>20^3>1300`.
Thus

```
F(t*) < 2000*34^6 < 10^13.
```

For t>=0, direct differentiation gives

```
F'(t)/F(t)
 = 1/(t+1003) + 6/((t+1000)*(log(t+1000)+25))
 < 7/1000 < 1.
```

Therefore for t>=t*, `10^172*F(t)<10^185*exp(t-t*)`.
In the same range,

```
M^2/100-20 > M^2/200
            = (10^200/200)*exp(2*(t-t*))
            > 10^197*exp(t-t*).
```

This contradicts (2). Hence `M<10^100` as claimed. Every comparison of
integer powers, rational finite series and numerical constants used here is
recorded by `certify_david_constants.py`; the theorem, period interpretation,
height theory, uniformization and calculus remain the human proof layer.
